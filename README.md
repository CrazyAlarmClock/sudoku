# Судоку с Мики и Марсиком

[Открыть игру](https://crazyalarmclock.github.io/sudoku/)

Классическое судоку без рекламы и регистрации: четыре уровня, заметки,
отмена, подсказки, светлая и тёмная темы. Мики и Марсик помогают играть.

## На iPhone

Откройте ссылку в Safari, выберите «Поделиться» → «На экран “Домой”».
Откройте установленную веб-игру с интернетом и дождитесь сообщения
«Можно играть без интернета». Затем можно играть без сети.

Первая полная загрузка занимает примерно 15 МиБ. Интернет понадобится
для загрузки обновлений. Прогресс хранится только в браузере на этом
устройстве; очистка данных сайта может удалить сохранение. Эта публикация
публичная. Серверной части, рекламы, регистрации и аналитики в игре нет.

## Публикация

Репозиторий содержит готовую статическую Flutter web-сборку для GitHub Pages.
Исходный Flutter-проект поддерживается в каталоге sudoku рабочего проекта games.
Сборка создаётся командой `python3 tools/build_web.py` из Flutter-проекта.

`precache-manifest.json` содержит SHA-256 и размер каждого файла игры.
Обновления устанавливаются после закрытия всех окон судоку, не прерывая партию.
